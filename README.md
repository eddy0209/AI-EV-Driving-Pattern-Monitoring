# 📌 Project Overview

This project focuses on developing an intelligent **Electric Vehicle (EV) monitoring and energy optimization system** using Artificial Intelligence, Machine Learning and Embedded Systems.

The system monitors driving behaviour and electrical parameters in real time to identify different driving patterns such as **Eco, Normal and Aggressive**.

Based on the detected driving behaviour, the system dynamically optimizes the motor power command using **PWM (Pulse Width Modulation)**.

The objective is to reduce unnecessary electrical power consumption, improve battery energy efficiency and potentially enhance the effective driving range of an Electric Vehicle.

The project combines **AI-based driving pattern detection, real-time sensor monitoring and PWM-based motor power optimization** into a single system.

---

# 🎯 Objectives

The major objectives of the project are:

- Monitor driving behaviour in real time
- Detect Eco, Normal and Aggressive driving patterns
- Monitor electrical parameters of the EV system
- Measure motor voltage and current
- Calculate real-time electrical power consumption
- Analyze the effect of driving behaviour on energy consumption
- Optimize motor power delivery using PWM
- Reduce unnecessary power consumption
- Improve battery energy efficiency
- Verify optimization using real hardware measurements
- Develop a prototype for intelligent EV energy optimization

---

# 💡 Problem Statement

Electric Vehicles are highly dependent on efficient utilization of battery energy.

Aggressive driving behaviour such as:

- Sudden acceleration
- High throttle input
- Frequent high-power operation
- Unnecessary motor power demand

can result in increased current consumption and higher electrical power demand.

A system that can identify inefficient driving behaviour and dynamically adjust motor power delivery can help reduce unnecessary energy consumption.

Therefore, this project proposes an **AI-based driving pattern monitoring and PWM optimization system** that analyzes driver behaviour and modifies motor power according to the detected driving condition.

---

# 🧠 Proposed Solution

The proposed system follows a closed-loop monitoring and optimization approach.

```text
Driver Input
     ↓
Throttle Monitoring
     ↓
Sensor Data Collection
     ↓
Driving Pattern Detection
     ↓
Eco / Normal / Aggressive
     ↓
Energy Consumption Analysis
     ↓
PWM Optimization
     ↓
Motor Power Control
     ↓
Power & Efficiency Measurement
     ↓
Optimization Verification

```
